# Dice Roller Utility

Утилита для бросков кубиков с поддержкой модификаторов. Доступна в двух режимах работы: **CLI** (консольный интерфейс) и **Web** (веб-интерфейс).

## Возможности

-   Сложные выражения (например, `2d6+1d4-3`).
-   Модификаторы броска (преимущество, помеха, умножение, деление).
-   История последних запросов.
-   Цветовое выделение результатов (в CLI и Web).

## Режимы работы

### 1. CLI (Командная строка)

Запуск осуществляется через скрипт `dice.py`.

**Интерактивный режим:**
```bash
./dice.py
```
-   Пустая строка ввода повторяет последний бросок.
-   Ввод цифры `0–9` повторяет соответствующий бросок из истории (0 — самый свежий).
-   Повторный бросок перемещается в начало истории.

**Одиночный расчёт (без консольного интерфейса):**
Используйте флаг `-s` или `--single`.
```bash
./dice.py -s "2d6+3"
```
Выполняет расчёт для переданной строки и выводит результат, после чего завершает работу.

**Справка:**
```bash
./dice.py -h
```

### 2. Web (Веб-интерфейс)

Веб-интерфейс предоставляет графическую панель для бросков, историю в локальном хранилище браузера и визуализацию результатов.

**Первичная настройка:**
Выполните скрипт инициализации (создаёт виртуальное окружение и устанавливает зависимости):
```bash
# Linux/macOS
./setup.sh

# Windows
setup.bat
```

**Запуск сервера:**
```bash
# Linux/macOS
source venv/bin/activate
python app.py

# Windows
venv\Scripts\activate
python app.py
```
После запуска интерфейс доступен по адресу `http://localhost:6767`.

## Синтаксис броска

Основной формат:  
`[±][N]dX[!*/?...]`

Где:
-   `N` — количество кубиков (по умолчанию 1),
-   `X` — число граней (например, `6`, `20`),
-   знак `+` или `-` — добавление или вычитание члена выражения,
-   можно указывать несколько членов: `2d6+1d4-5`.

### Спецсимволы (в конце каждого члена)

| Символ | Эффект |
|--------|--------|
| `!`    | **Преимущество** — бросить дважды и взять максимальный результат. Несколько `!` не усиливают эффект. |
| `?`    | **Помеха** — бросить дважды и взять минимальный результат. |
| `*`    | **Уязвимость** — умножить итог на 2. |
| `/`    | **Сопротивление** — умножить итог на 0.5. |

**Правила комбинирования:**
-   Если `*` и `/` встречаются в равном количестве — модификатор не применяется.
-   Если `?` и `!` встречаются в равном количестве — происходит один обычный бросок.

**Примеры:**
-   `d20!` — бросить d20 дважды, взять лучший.
-   `3d6??` — бросить 3d6 дважды, взять худший.
-   `2d8*` — бросить 2d8 и удвоить результат.
-   `1d4*/` — без модификатора (один `*`, один `/`).
-   `4d4?!` — бросить 4d4 без помехи и преимущества.

## Установка и требования

-   **Python:** 3.7 и выше.
-   **Зависимости:**
    -   Для CLI: только стандартная библиотека Python.
    -   Для Web: Flask (устанавливается скриптом `setup.sh`/`bat`).

## Примечания

-   Поддерживается замена `к` на `d`: `2к6` → `2d6`.
-   Все пробелы в строке запроса игнорируются.
-   Цветовая подсветка работает в ANSI-совместимых терминалах.
